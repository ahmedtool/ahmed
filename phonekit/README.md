# PhoneKit 📱

تطبيق سطح مكتب بسيط لإدارة جوال **أندرويد** من الكمبيوتر عن طريق كيبل USB.

## الخصائص الثلاث
1. **معلومات الجهاز**: الشركة، الموديل، إصدار أندرويد، البطارية، حالة الشحن، المساحة.
2. **نسخ احتياطي**: ينسخ الصور والكاميرا والتنزيلات والمستندات وغيرها من الجوال إلى الكمبيوتر.
3. **نقل ملفات للجوال**: ينقل ملفات أو مجلد كامل من الكمبيوتر إلى الجوال.

## التشغيل (٣ خطوات)
1. ثبّت **Python 3** من python.org (على ويندوز فعّل خيار *Add Python to PATH*).
2. نزّل **Android Platform Tools** من:
   https://developer.android.com/tools/releases/platform-tools
   وفك الضغط وحط مجلد `platform-tools` **جنب ملف** `phonekit.py`.
3. شغّل:
   ```
   python phonekit.py
   ```
   أو على ويندوز دبل كليك على `run.bat`.

## تجهيز الجوال
- الإعدادات ← حول الهاتف ← اضغط على **رقم الإصدار** ٧ مرات (تنفتح خيارات المطور).
- الإعدادات ← خيارات المطور ← فعّل **تصحيح USB**.
- وصّل الكيبل ووافق على رسالة **السماح بتصحيح USB** في الجوال.
- اضغط **🔄 تحديث** في البرنامج.

## تحويله لملف exe (اختياري)
```
pip install pyinstaller
pyinstaller --onefile --windowed phonekit.py
```
وحط مجلد `platform-tools` جنب ملف الـ exe الناتج في `dist/`.
