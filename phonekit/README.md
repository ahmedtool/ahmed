# PhoneKit 📱

تطبيق سطح مكتب بسيط لإدارة الجوال من الكمبيوتر عن طريق كيبل USB.
يدعم **أندرويد 🤖** و **آيفون 🍎** ويتعرف على نوع الجوال تلقائياً.

## الخصائص الثلاث
| الخاصية | أندرويد | آيفون |
|---|---|---|
| **معلومات الجهاز** | الموديل، الإصدار، البطارية، الشحن، المساحة | نفسها |
| **نسخ احتياطي** | الكاميرا، الصور، التنزيلات، المستندات، الفيديو، الموسيقى | الصور والفيديوهات + نسخة كاملة للجهاز (مثل iTunes) |
| **نقل ملفات للجوال** | لأي مجلد (التنزيلات، الصور...) | لتطبيق يقبل ملفات (VLC، Documents...) وتلقاها في تطبيق **الملفات** |

## التشغيل
1. ثبّت **Python 3** من python.org (على ويندوز فعّل خيار *Add Python to PATH*).
2. دبل كليك على `run.bat` (يثبّت المكتبات ويشغّل البرنامج)، أو:
   ```
   pip install -r requirements.txt
   python phonekit.py
   ```

### للأندرويد
- نزّل **Android Platform Tools** من:
  https://developer.android.com/tools/releases/platform-tools
  وحط مجلد `platform-tools` **جنب** ملف `phonekit.py`.
- في الجوال: الإعدادات ← حول الهاتف ← اضغط **رقم الإصدار** ٧ مرات، ثم خيارات المطور ← فعّل **تصحيح USB**.
- وصّل الكيبل ووافق على رسالة **السماح بتصحيح USB**.

### للآيفون
- على ويندوز: ثبّت تطبيق **Apple Devices** (أو **iTunes**) من متجر مايكروسوفت، عشان تعريفات USB.
  على الماك ما تحتاج شي.
- وصّل الآيفون، افتح القفل، واضغط **ثقة (Trust)** وأدخل الرمز.
- للنقل للآيفون: لازم يكون فيه تطبيق يقبل ملفات، مثل **VLC** أو **Documents**.
- إذا النسخة الاحتياطية مشفّرة في الآيفون، ممكن يطلب منك الرمز.

ثم اضغط **🔄 تحديث** في البرنامج.

## تحويله لملف exe (اختياري)
```
pip install pyinstaller
pyinstaller --onefile --windowed --collect-all pymobiledevice3 phonekit.py
```
وحط مجلد `platform-tools` جنب ملف الـ exe الناتج في `dist/`.
