# بوت تحميل المقاطع والصور (شخصي)

بوت تيليجرام ترسل له رابط ويرد عليك بالمقطع أو الصورة.

المنصات: سناب شات، اكس، يوتيوب، انستجرام، تيك توك، فيس بوك.

البوت خاص: يرد فقط على الحسابات الموجودة في `ALLOWED_USER_IDS` ويتجاهل أي شخص آخر.

## الإعداد

1. افتح [@BotFather](https://t.me/BotFather) في تيليجرام، أرسل `/newbot`، وانسخ التوكن.
2. انسخ ملف الإعدادات وضع التوكن فيه:
   ```bash
   cp .env.example .env
   ```
3. شغّل البوت (الخطوة التالية)، أرسل له `/start`، وراح يعطيك رقم حسابك.
4. ضع الرقم في `ALLOWED_USER_IDS` داخل `.env` وأعد تشغيل البوت.

## التشغيل

بـ Docker (الأسهل على أي سيرفر):

```bash
docker build -t media-bot .
docker run -d --name media-bot --restart unless-stopped --env-file .env media-bot
```

أو مباشرة (يحتاج Python 3.10 أو أحدث و `ffmpeg`):

```bash
pip install -r requirements.txt
set -a; source .env; set +a
python bot.py
```

## ملاحظات

- **حجم الملفات:** حد تيليجرام للبوتات 50 ميجا. البوت ينزّل بجودة 720 وإذا كان الملف أكبر يجرب 480 ثم 360.
- **المحتوى الخاص:** يحتاج ملف cookies من متصفحك بصيغة Netscape، وتحدد مساره في `COOKIES_FILE`. فيه احتمال أن المنصة تقيّد الحساب.
- **التحديث:** المنصات تتغير باستمرار. إذا توقف التحميل من منصة، حدّث المكتبات:
  ```bash
  pip install -U yt-dlp gallery-dl
  ```
  أو أعد بناء صورة Docker بـ `--no-cache`.
- **الاستضافة:** البوت لازم يشتغل طول الوقت، فيحتاج VPS أو خدمة مثل Railway. خدمات serverless مثل Vercel ما تناسبه.
