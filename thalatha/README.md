# ٣ — موقع محتوى عربي

موقع ثابت (HTML + CSS + JavaScript) بلا مكتبات ولا خطوة بناء، بواجهة عربية من اليمين إلى اليسار.

## التشغيل

افتح `thalatha/index.html` في المتصفح، أو انشر مجلد `thalatha` على أي استضافة ثابتة.

## الواجهات

| المسار | الواجهة |
|---|---|
| `#/` | الرئيسية: بانر، أحدث المقالات، الحلقات، النشرات، البرامج |
| `#/articles` | المقالات: مقالة رئيسية وقائمة مع «المزيد» |
| `#/radio` | الإذاعة: البرامج الصوتية والحلقات مع مشغّل مصغّر (تجريبي بلا صوت) |
| `#/programs` | البرامج المرئية |
| `#/a/<id>` | صفحة قراءة المقالة |
| `#/n/<id>` | صفحة النشرة البريدية وأعدادها |

ومعها: بحث، نافذة اشتراك، نافذة دخول (تجريبية لا ترسل شيئًا)، ومظهر فاتح/داكن.

## التخصيص

- المحتوى كله في `js/data.js` (مقالات، نشرات، برامج، حلقات).
- الألوان والخط والمقاسات متغيرات في أعلى `css/style.css`.
- الرسومات مولّدة بـ CSS دون صور خارجية.
