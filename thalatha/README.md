# ٣ — موقع محتوى عربي

موقع ثابت (HTML + CSS + JavaScript) بلا أي مكتبات أو خطوة بناء، بواجهة عربية من اليمين إلى اليسار.

## التشغيل

افتح `thalatha/index.html` في المتصفح، أو انشر مجلد `thalatha` على أي استضافة ثابتة (GitHub Pages، Vercel، Netlify).

## المحتويات

- رأس ثابت مع تنقل، وقائمة للجوال، وتبديل المظهر الفاتح/الداكن
- واجهة رئيسية للحلقة المميزة وشريط متحرك
- شريط برامج البودكاست مع مشغّل مصغّر (تجريبي بلا صوت)
- شبكة مقالات مع تصفية حسب التصنيف
- قسم الوثائقيات، قسم «من نحن» بعدّادات، نموذج النشرة البريدية، وتذييل

## التخصيص

الألوان والخطوط والمقاسات كلها متغيرات في أعلى `css/style.css` (`--accent`، `--yellow`، `--green`…).
النصوص والمحتوى في `index.html`، وكل الرسومات مصنوعة بـ CSS دون صور خارجية.
