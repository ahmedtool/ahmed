# ميزان — نظام محاسبي عربي متكامل

نظام محاسبة بالقيد المزدوج يعمل بالكامل في المتصفح (HTML + CSS + JavaScript) دون أي خادم أو مكتبات خارجية، بواجهة عربية بالكامل من اليمين إلى اليسار.

## التشغيل

- افتح الملف `index.html` مباشرة في المتصفح، أو انشر المجلد على أي استضافة ثابتة (GitHub Pages، Netlify، Vercel…).
- **كلمة المرور المؤقتة: `1234`** — غيّرها من «الإعدادات ← تغيير كلمة المرور».
- عند أول تشغيل يُحمَّل نظام ببيانات تجريبية لمؤسسة افتراضية لتوضيح العمل؛ اضغط «ابدأ بنظام فارغ» للبدء ببياناتك.

## أكثر من ٣٠٠ عملية محاسبية

افتح **مركز العمليات** أو اضغط `Ctrl + K` للبحث في كل العمليات:

| التصنيف | أمثلة |
|---|---|
| قوالب قيود جاهزة (١١٤ قالباً) | رأس المال والقروض، الإيجار والمرافق، المقدمات والمستحقات، المخصصات، الرواتب والسلف، شراء الأصول، الضريبة والزكاة، فروقات العملة |
| المستندات | فواتير المبيعات والمشتريات والمرتجعات، عروض الأسعار وتحويلها، سندات القبض والصرف، الشيكات الواردة والصادرة (تحصيل/ارتداد) |
| المخزون | أصناف بمتوسط تكلفة مرجح، تكلفة البضاعة المباعة تلقائياً، بطاقة صنف، تسوية الجرد، حد إعادة الطلب |
| الأصول والرواتب | سجل الأصول، الإهلاك الشهري (ثابت/متناقص مضاعف)، البيع والاستبعاد، مسير الرواتب، التأمينات، مخصص نهاية الخدمة |
| الضرائب | إقرار ضريبة القيمة المضافة وتسويتها، حساب الزكاة التقديري، ضريبة الاستقطاع |
| التقارير | ميزان المراجعة، قائمة الدخل، المركز المالي، التدفقات النقدية، التغيرات في حقوق الملكية، أعمار الديون، تحليل المبيعات والربحية، الموازنة مقابل الفعلي، مراكز التكلفة |
| الحاسبات (١١١ حاسبة) | القيمة الحالية والمستقبلية، القروض وجداول السداد، NPV وIRR، الإهلاك بأنواعه، نقطة التعادل، FIFO/LIFO، EOQ، الانحرافات المعيارية، النسب المالية من الدفاتر، نموذج ألتمان، مكافأة نهاية الخدمة، تفقيط المبالغ، التاريخ الهجري |

## البنية

```
index.html            هيكل الصفحة
assets/css/app.css    التصميم (فاتح/داكن، متجاوب مع الجوال، طباعة)
assets/js/core.js     الأدوات، التخزين، دليل الحسابات، محرك القيد المزدوج، الفواتير
assets/js/ops.js      سجل العمليات المحاسبية والحاسبات
assets/js/pages.js    الصفحات والتقارير
assets/js/app.js      الدخول، التنقل، لوحة الأوامر، البيانات التجريبية
tools/build-single.js بناء نسخة ملف واحد: node tools/build-single.js → dist/mizan.html
```

- كل قيد يُتحقق من توازنه قبل الترحيل، والقيود المرتبطة بمستندات تُلغى بقيد عكسي حفاظاً على مسار التدقيق.
- الأرصدة تُحسب لحظياً من القيود مع ذاكرة مؤقتة تُبطل عند أي تغيير.

## ملاحظات مهمة

- **البيانات تُحفظ في متصفحك على هذا الجهاز فقط** (localStorage). نزّل نسخة احتياطية من الإعدادات بانتظام، ويمكن استعادتها على أي جهاز.
- كلمة المرور قفل محلي للواجهة وليست حماية أمنية للبيانات؛ لا تستخدم النظام على جهاز مشترك دون نسخ احتياطي وحذف البيانات.
- الحسابات الضريبية والزكوية تقديرية مبسطة، وتُراجع مع الإقرارات الرسمية.
